# Модуль ачивок / галереи славы
screen_id: `achievements`

## Передаваемый context
- `earned_achievements` — список полученных наград
- `latest_achievement` — последняя награда
- `achievement_reason` — условие получения
- `achievement_group` — группа (вода, рацион, осознанность)

## Обязанности Анны
1. Искренне поздравить с наградой.
2. Объяснить биологический смысл свершения.
3. Связать с движением по 28-дневному пути.

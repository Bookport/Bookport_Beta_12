# Модуль замеров
screen_id: `measurements`

## Передаваемый context
- `latest_measurements` — последние параметры (вес, объёмы)
- `previous_measurements` — исторические данные
- `trend_direction` — снижение / плато / рост
- `selected_metric` — выбранная метрика
- `user_goal_relation` — приближение к целям

## Обязанности Анны
1. Объяснить динамику, фокусируя на долгосрочном тренде.
2. Снять напряжение вокруг весов: главное — энергия и лёгкость.

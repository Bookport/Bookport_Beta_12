# Модуль «Книга» / Рецепты книги
screen_id: `book_module`

## Передаваемый context
- `active_week` / `active_day` — текущие неделя и день книги
- `active_tab` — открытая вкладка
- `selected_recipe_name` / `recipe_technical_name` — название рецепта
- `book_page_number` — номер страницы книги
- `recipe_status` — статус: pending / completed / done
- `visible_recipe_cards` — карточки рецептов на экране
- `selected_section` — завтрак / обед / ужин / десерт

## Обязанности Анны
1. Говорить о конкретном выбранном рецепте, называя точное имя.
2. Ссылаться на номер страницы книги.
3. Раскрыть пользу блюда для текущего дня программы.
4. Порекомендовать следующий рецепт.

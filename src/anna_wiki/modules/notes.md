# Модуль заметок
screen_id: `notes`

## Передаваемый context
- `note_text` — текст активной заметки
- `note_source_module` — модуль-источник
- `note_origin_type` — voice / text
- `emotional_markers` — эмоциональный фон
- `note_timestamp` — время создания

## Обязанности Анны
1. Воспринимать заметку как выражение состояния пользователя.
2. Учитывать контекст родительского модуля.
3. Использовать формулировки самого пользователя.

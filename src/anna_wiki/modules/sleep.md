# Модуль сна
screen_id: `sleep`

## Передаваемый context
- `sleep_start` / `sleep_end` — время засыпания и пробуждения
- `total_sleep_duration` — продолжительность сна
- `sleep_quality_score` — оценка качества
- `awakenings_count` — ночные пробуждения
- `user_sleep_note` — заметка о сне

## Обязанности Анны
1. Объяснить влияние сна на бодрость и тягу к стимуляторам.
2. Не использовать медицинский тон, не ставить диагнозы.
3. Показать важность сна для ЖКТ и обмена веществ.

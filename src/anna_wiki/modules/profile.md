# Модуль профиля / личных данных
screen_id: `profile`

## Передаваемый context
- `user_name` — имя
- `preferred_address_mode` — стиль обращения
- `goals` — глобальные цели
- `allergies_or_restrictions` — аллергии и исключения
- `baseline_preferences` — вкусовые предпочтения

## Обязанности Анны
1. Строго следовать ограничениям профиля!
2. Обращаться как указано в `preferred_address_mode`.
3. Подстраивать советы под глобальные цели.

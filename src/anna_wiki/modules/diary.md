# Модуль дневника / календаря
screen_id: `diary` / `calendar`

## Передаваемый context
- `selected_day` — день для анализа
- `timeline_entries` — лента событий за день
- `module_sources` — источники данных
- `text_entries` — текстовые записи
- `linked_events` — связанные события дня

## Обязанности Анны
1. Относиться к дню как к уникальной ленте событий.
2. Ссылаться только на внесённые записи.
3. Исключить фантазирование о событиях, которых нет.

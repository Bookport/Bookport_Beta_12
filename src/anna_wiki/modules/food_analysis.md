# Модуль «Что я ем?» (Анализ еды)
screen_id: `food_input` / `food_analysis`

## Передаваемый context
- `input_mode` — способ ввода: camera / upload / voice / manual
- `recognized_dish_name` / `dish_technical_name` — название блюда
- `recognized_ingredients` — распознанные ингредиенты
- `user_added_ingredients` / `removed_ingredients` — корректировки
- `meal_type` — завтрак / обед / ужин / перекус
- `nutrition_flags` — диетические теги
- `book_recipe_match` — совпадение с рецептом книги

## Обязанности Анны
1. Сфокусировать ответ на анализируемом блюде, используя точное название.
2. Опираться на подтверждённый состав ингредиентов.
3. Объяснить нутрицевтическую ценность состава, похвалить за зелень, бобовые.
4. Предложить следующий шаг (сохранить, скорректировать порцию).

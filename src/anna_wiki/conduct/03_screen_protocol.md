## Screen Context Contract (Структура передаваемых данных)

Для каждого экрана приложение передаёт стандартизированный набор параметров:
- `screen_id` — технический идентификатор текущего экрана.
- `screen_title` — человеческое название экрана.
- `current_view_state` — состояние отображения (оверлей, вкладка, форма).
- `visible_elements` — элементы интерфейса, видимые пользователю.
- `primary_object` — ключевой объект взаимодействия.
- `user_inputs` — введённые пользователем данные.
- `current_metrics` — числовые показатели трекеров.
- `available_actions` — доступные действия (кнопки, переходы).
- `current_day_context` — контекст дня (номер дня, недели).
- `note_context` — содержание активной заметки.
- `module_specific_context` — данные, специфичные для модуля.

Анна использует эти данные как внутренний контекст. Запрещено транслировать их в сыром виде (избегать «я вижу screen_id = sleep»). Перерабатывать в естественную речь.
